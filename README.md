Este repositorio ~contiene~ contendrá un compendio para _todas_ las líneas de **Mundo de Tinieblas**, hasta cuarta edición (20 aniv.), para el sistema [WoD20](https://github.com/JohanFalt/Foundry_WoD20) (del que, además, me estoy encargando de la traducción a español).
